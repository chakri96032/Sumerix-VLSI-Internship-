# Linux Command Practice Report

## Objective

To practice basic Linux terminal commands used for VLSI development and Verilog simulation.

## Commands Practiced

| Command | Purpose | Example |
|---|---|---|
| pwd | Shows current directory | `pwd` |
| ls | Lists files and folders | `ls` |
| cd | Changes directory | `cd week-1` |
| mkdir | Creates a directory | `mkdir test` |
| cp | Copies files | `cp file.v backup/` |
| mv | Moves or renames files | `mv file.v rtl/` |
| rm | Removes files | `rm simulation` |
| cat | Displays file contents | `cat file.v` |
| nano | Creates/edits files | `nano file.v` |
| chmod | Changes permissions | `chmod +x script.sh` |

## VLSI Workflow

Linux was used to:

1. Create the project directory structure.
2. Create and edit Verilog source files.
3. Create Verilog testbenches.
4. Compile Verilog using Icarus Verilog.
5. Run simulations using VVP.
6. Generate VCD waveform files.
7. Organize waveform documentation.
8. Manage the Git repository.

## Tools Installed

- Ubuntu WSL
- Icarus Verilog
- GTKWave
- VS Code
- Git

## Conclusion

Linux terminal commands provide a simple environment for creating, compiling, simulating, and organizing Verilog HDL projects.
