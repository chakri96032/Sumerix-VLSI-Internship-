# Digital Arithmetic Logic Circuit Library Using Verilog HDL

## Overview

This mini-project is a reusable digital circuit library developed using Verilog HDL.

## Circuits Included

### Logic Gates
- AND Gate
- OR Gate
- XOR Gate
- NOT Gate
- NAND Gate
- NOR Gate
- XNOR Gate

### Combinational Circuits
- 2-to-1 Multiplexer
- Half Adder
- Full Adder
- 4-bit Ripple Carry Adder

## Verification

Each circuit is verified using a dedicated Verilog testbench.

Simulation is performed using Icarus Verilog.

Waveforms are analyzed using GTKWave.

## Tools Used

- Verilog HDL
- Icarus Verilog
- GTKWave
- VS Code
- Ubuntu WSL
- Git
- GitHub
