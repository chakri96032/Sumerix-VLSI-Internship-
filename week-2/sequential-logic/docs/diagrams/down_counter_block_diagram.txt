4-BIT DOWN COUNTER — RTL BLOCK DIAGRAM

                 ┌─────────────────────────┐
                 │                         │
CLK ────────────►│                         │
                 │    4-BIT DOWN COUNTER   │────► Q[3:0]
RESET ──────────►│                         │
                 │                         │
                 └─────────────────────────┘

FUNCTION:
The counter decrements by 1 on every rising edge of CLK.

RESET:
When RESET is active, Q is set to 1111.

OUTPUT:
Q[3:0] = 4-bit counter value.
