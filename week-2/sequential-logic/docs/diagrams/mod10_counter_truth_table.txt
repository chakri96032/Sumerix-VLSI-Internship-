MOD-10 COUNTER — TRUTH TABLE

RESET    CLOCK EDGE       CURRENT Q       NEXT Q
------------------------------------------------
  1          ↑             XXXX          0000
  0          ↑             0000          0001
  0          ↑             0001          0010
  0          ↑             0010          0011
  0          ↑             0011          0100
  0          ↑             0100          0101
  0          ↑             0101          0110
  0          ↑             0110          0111
  0          ↑             0111          1000
  0          ↑             1000          1001
  0          ↑             1001          0000

NOTE:
↑ represents the rising edge of the clock.

The counter has ten valid states: 0 through 9.

When Q = 1001 (decimal 9), the next state is 0000.

The counter therefore repeats:

0 → 1 → 2 → ... → 9 → 0
