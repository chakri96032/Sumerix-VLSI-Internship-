4-BIT DOWN COUNTER — TRUTH TABLE

RESET    CLOCK EDGE       CURRENT Q       NEXT Q
------------------------------------------------
  1          ↑             XXXX          1111
  0          ↑             1111          1110
  0          ↑             1110          1101
  0          ↑             1101          1100
  0          ↑             1100          1011
  0          ↑             1011          1010
  0          ↑             1010          1001
  0          ↑             1001          1000
  0          ↑             1000          0111
  0          ↑             0111          0110
  0          ↑             0110          0101
  0          ↑             0101          0100
  0          ↑             0100          0011
  0          ↑             0011          0010
  0          ↑             0010          0001
  0          ↑             0001          0000
  0          ↑             0000          1111

NOTE:
↑ represents the rising edge of the clock.

When RESET = 1, the counter is set to 1111.
When RESET = 0, the counter decrements by 1 at each
rising edge of CLK.

The counter wraps from 0000 back to 1111.
