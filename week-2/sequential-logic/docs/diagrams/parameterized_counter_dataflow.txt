PARAMETERIZED N-BIT COUNTER — DATA FLOW

          +-------+
CLK ----->|       |
          | COUNT |-----> Q[WIDTH-1:0]
RESET --->| LOGIC |
          +-------+
               ^
               |
          Q + 1 FEEDBACK

DATA FLOW:
1. Current Q value is stored in the register.
2. Adder generates Q + 1.
3. On rising CLK edge:
      Q <= Q + 1
4. If RESET = 1:
      Q <= 0

EXAMPLE:
0 -> 1 -> 2 -> 3 -> ... -> MAX -> 0
