4-BIT UP COUNTER — TRUTH TABLE

RESET    CLOCK EDGE       CURRENT Q       NEXT Q
------------------------------------------------
  1          ↑             XXXX          0000
  0          ↑             0000          0001
  0          ↑             0001          0010
  0          ↑             0010          0011
  0          ↑             0011          0100
  0          ↑             0100          0101
  0          ↑             0101          0110
  0          ↑             0110          0111
  0          ↑             0111          1000
  0          ↑             1000          1001
  0          ↑             1001          1010
  0          ↑             1010          1011
  0          ↑             1011          1100
  0          ↑             1100          1101
  0          ↑             1101          1110
  0          ↑             1110          1111
  0          ↑             1111          0000

NOTE:
↑ represents the rising edge of the clock.

When RESET = 1, the counter is cleared to 0000.
When RESET = 0, the counter increments by 1 at each
rising edge of CLK.

The counter wraps from 1111 back to 0000.
